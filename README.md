# Memory Game

A classic memory match game: 16 cards with 8 different Minecraft-style
images. The player flips two cards per move, trying to find all pairs
in the fewest moves possible.

## Demo

[Play](https://annstarrysky.github.io/memory-game/)

## How to play

- Click a card to flip it face up.
- Flip a second card: if the images match, the pair stays open;
  if not, both cards close after one second.
- Goal — find all 8 pairs in the fewest number of moves.
- The **New Game** button in the header starts a new game.
- The **Leaderboard** button opens a table with the top 10 results.
- Modals close via the Close button, a click on the backdrop,
  or the Escape key.

## Local setup

1. Install the **Live Server** extension in VS Code.
2. Open the project folder in VS Code.
3. Right-click on `index.html` → **Open with Live Server**.
4. The app opens at `http://127.0.0.1:5500`.
